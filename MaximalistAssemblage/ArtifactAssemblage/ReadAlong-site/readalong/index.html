Read Along

    How to add a book
    1. Press Add a book or files and pick the book's reading script, the file ending in _reading_script.txt.
    2. In the same step, or later, pick each chapter's MP3 and its .timings.json file from the book's _audio folder. You can pick many at once.
    3. To bring marks from another device, pick the marks file you saved there, ending in _marks.json.

    Books are copied into this browser's storage on this device. Nothing is uploaded.
